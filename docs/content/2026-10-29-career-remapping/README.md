The articles share the remapping proposal's method: **actual tasks → transferable capabilities → plausible directions → a gap-closing project → evidence-backed positioning**. They do not represent the local prototype as a released service. Role directions are hypotheses to check against current employer requirements, not verified vacancies or automatic title equivalences.

The supplied Search Console URL names stackcut.io. The product request, project, linked chat, and existing signed-in tutor report establish myaiskilltutor.com as this review's scope. Stackcut's data was not mixed into the tutor's results. “AHF” was interpreted as Ahrefs; “temp poll” as tentpole content.

Existing untracked planning, generated images, and prototype files were preserved. The release adds structured article blocks and workbook download links to the existing learning renderer. Its checks and release status are recorded in RELEASE.md. The private search report remains in the original local project packet and is excluded from the publishing commit.
